# 운동 시작·종료

출발 대기와 종료 안내의 서비스 상태·측정·오디오 계약을 설명한다.

## 출발

기본은 꺼짐(0초), 설정은 1~60초다. 기존 `TaskSheet`·숫자 패드·프리셋·1초 증감·적용/취소 방식을 사용한다. 잘못된 저장값은 즉시 시작으로 복구한다. 기존 권한 요청을 마친 뒤 정확한 위치 권한·위치 기능과 목표/계획 범위를 확인한다. 첫 GPS나 케이던스 수신 자체를 시작 조건으로 강제하지 않는다.

`RunScreen`의 `RunSummary(startedAt=0)`는 기존 권한 요청/서비스 payload와 호환하는 출발 설정 사본이다. DB 기록이나 측정 엔진은 만들지 않는다. 서비스의 `RunStartPolicy`가 단조시계 마감시각과 요청 ID를 소유한다. 카운트다운 동안 센서를 등록하거나 거리·시간·구간을 누적하지 않는다. 실제 출발 때 현재 epoch 시각의 새 `RunSummary`와 엔진을 생성·저장하고 시작 안내를 큐에 한 번 넣는다. 이전 GPS/걸음 이벤트는 실제 시작의 단조시각보다 이전이면 제외한다.

남은 초와 취소만 표시하며 뒤로 가기도 취소한다. 중복 START는 대기/진행 운동을 교체하거나 마감시각을 바꾸지 않는다. 회전·재구성·탭 이동·앱 전환은 서비스 상태를 다시 구독한다. 백그라운드에서도 같은 마감시각에 출발하며 지연된 이벤트는 처리 시점에 한 번만 시작하고 준비 시간을 소급하지 않는다. 프로세스 종료/서비스 파괴는 저장하지 않은 준비를 취소한다. START_STICKY 복구는 미완료 운동만 복구하며 출발 대기를 복원하지 않는다. 기존 운동 재개/복구에는 새 대기나 시작 안내를 넣지 않는다.

## 종료 안내와 정리

FINISH는 이전 코칭 큐·경보·음성을 정리하고 엔진을 종료한 뒤 전체 요약을 먼저 checkpoint한다. 위치·걸음 구독을 해제하고, 저장한 동일 요약/전체 점에서 종료 문장을 만든다. 목표 이후 추가 기록도 거리·평균 페이스·케이던스에 포함한다. 거리 발화는 기록 표시와 같은 소수 두 자리 km 반올림이며 0km로 반올림되는 양수 거리는 m로 읽는다. 페이스는 기존 `paceSpeechText`를 사용한다. 평균 케이던스는 전체 기록 점의 유효한 양수 실측값 산술평균으로, 기존 기록 표시와 같은 샘플 평균 정책이다. 목표 메트로놈은 사용하지 않는다. 없는/비유한/0·음수 수치와 계산 불가능 페이스는 생략한다.

시작/종료는 `paceVoice`·상태/현재/목표 선택과 독립적이다. 앱 전체 `voice`와 공통 음량·속도·높낮이를 적용한다. 음성 꺼짐/음량 0이면 종료 기록은 저장하고 즉시 자원을 정리한다. 종료 음성의 초기화/포커스 대기는 최대 5초, 수락된 재생은 최대 30초다. 완료·오류·중지(포커스 손실 포함)는 같은 티켓의 정리 이벤트를 보낸다. 기록 저장은 성공 콜백을 기다리지 않는다. 콜백 누락에도 한정된 시간 뒤 정리한다. 타이머 주기 때문에 최종 정리는 한 틱 늦을 수 있다.

중복 FINISH는 재발화/재저장하지 않는다. 달리기 화면의 정지/재개/종료와 준비 취소는 대상 운동/준비 ID를 전달하므로 이전 화면의 늦은 명령이 다음 운동을 종료하거나 취소하지 않는다. 다음 새 START는 이전 종료 티켓·플레이어를 취소하고 새 운동 cue 초기화를 유지한다. 늦은 TTS 콜백은 발화 ID와 종료 티켓, 기존 코칭의 엔진/세션 요청으로 격리한다. 이미 도착한 새 서비스 명령이 처리되기 전에는 이전 정리 이벤트가 서비스를 중지하지 않도록 startId를 확인한다. 프로세스 재시작에서 저장된 FINISHED 기록의 종료 문장은 다시 재생하지 않는다.

## 검증

자동 검사 설정·범위와 공개 CI 상태는 [검증 기록](VALIDATION.md)에 정리한다. GitHub Actions는 JDK 25 / JVM 21 / JUnit 5에서 core·simulation 단위 테스트와 preview/kakao debug·simulation 네 variant 빌드·lint를 수행하도록 설정되어 있다.

새 순수 정책 회귀는 0/1/60초·범위밖/저장 호환, 마감 경계/중복 요청·취소/늦은 이벤트, 상태 재구독/지연/프로세스 준비 취소, 실제 엔진의 대기 시간 제외·재개/복구, 전체 종료 통계/유효 실측·분초, 완료/실패 정리·초기화/포커스 대기 제한·중복 종료·다음 세션/늦은 콜백을 확인한다. 이는 Android 서비스/UI 실행이나 실제 TTS 콜백·음성 출력 성공을 입증하는 검사가 아니다. 기존 오디오 및 UI 회귀는 유지한다.

실제 한국어 음성 청취·이어폰/전화·화면 꺼짐·회전/복구 UI 조작·야외 GPS는 미실행이다.
