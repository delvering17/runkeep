# UI 문구 점검

2026-10-10, `app/src/main`의 모든 화면·공통 컴포넌트와 위치/음성/알림 상태, `kakao`/`preview` 지도, `core`의 표시·음성 안내를 읽고 점검했다. 감성·홍보 문구, 값이나 컨트롤이 이미 보여주는 설명, 중복 제목을 없앴다. 입력 대상·단위·측정 기준, 사용자가 다음 행동을 판단하는 상태·권한·오류·파괴적 확인은 유지하거나 줄였다.

[거리 입력 정책](DISTANCE_INPUT_VALIDATION.md)은 문자 입력 제한, 프리셋과 오른쪽 단위 선택 구조를 설명한다. 여기서는 공통 문구와 정상 상태 설명만 정리했다. 거리의 입력 로직, 기존 프리셋 수치·숫자 검증, 저장 단위, 서비스·도메인 동작은 바꾸지 않았다.

## 검증

빌드·lint와 실제 화면 확인 결과는 [UI 문구 확인 범위](UI_COPY_VALIDATION.md)에 별도로 기록한다. 문자열 치환을 그대로 따라하는 테스트는 추가하지 않는다. 측정·입력·저장 알고리즘은 이번 변경 범위 밖이다.
