# 코스 목록 정렬·달린 기록 필터

목록 상단 왼쪽은 현재 정렬을 보여주는 공통 `SelectionRow`, 오른쪽은 처음 켜진 **달린 기록** 체크다. 정렬은 `DomainSelectionSheet`의 라디오 선택으로 후보를 고르고 적용한다. 취소·뒤로·바깥 닫기는 기존 선택을 유지한다. 정렬·필터는 탭 상태와 Activity 재생성에서 유지하며 영구적으로 코스를 변경하지 않는다.

| 정렬 | 비교 기준 |
| --- | --- |
| 최신 등록 순 | DAO의 명시적 `ORDER BY rowid DESC` 입력 순서 |
| 거리 긴 순 / 짧은 순 | 저장 좌표의 코스 총거리(m) |
| 목표 페이스 빠른 순 / 느린 순 | 모든 유효 길이 구간에 목표가 설정된 코스의 거리 가중 예상 평균(s/km) |
| 달린 횟수 많은 순 / 적은 순 | 종료된 기록의 코스 사본 ID가 현재 코스 ID와 일치한 횟수 |

숫자값이 같으면 변경되지 않는 코스 ID의 오름차순을 보조 키로 사용한다. 목표 평균은 코스 목표의 `paceEstimate()`의 예상 시간 / 총거리로 계산한다. 실제 달리기 평균 페이스와 별개다. 목표 사용 꺼짐, 목표 없음, 일부 구간 미설정, 총거리 0은 정렬용 목표가 없으며 빠른 순과 느린 순 모두 마지막에 둔다. 일부 목표는 행에서 **목표 일부 미설정**, 나머지는 **목표 미설정**으로 구분한다.

## 등록·기록 연결의 근거와 한계

`Course`에는 등록 날짜가 없고 `CourseRow`는 TEXT 기본키와 payload만 저장한다. 최신 등록은 날짜를 추정하지 않고 현재 SQLite 테이블의 실제 삽입 순서 `rowid`로 정의한다. Room `@Upsert`에서 기존 ID의 이름/지점 변경은 UPDATE로 처리되어 삽입 순서를 유지한다. 삭제 후 재등록·파일 가져오기의 새 ID는 새 등록이다. 별도 시간 필드나 스키마 마이그레이션은 추가하지 않는다. 이 정책은 DB 복원/외부 삽입 순서까지 과거의 실제 달력상 등록 날짜로 보장하지 않는다.

`RunSummary.course`에는 운동 당시 코스 사본의 `id`가 있다. 저장 코스 이름/지점을 바꿔도 사본은 원래 ID를 유지하므로 이름 변경 후 같은 코스의 종료 기록이 연결된다. 동명 코스는 별개의 ID이며 서로 연결하지 않는다. 삭제된 코스의 사본 ID는 현재 목록에 없으므로 다른 코스로 옮겨 세지 않는다. 이전 기록의 `course = null` 등 연결 자료가 없으면 이름·좌표·운동 계획으로 임의 연결하지 않는다. 종료되지 않은 운동은 달린 기록 횟수에 포함하지 않으며 같은 기록 ID의 중복 관찰은 한 번만 센다. 저장된 원본 기록·코스는 수정하지 않는다.

Root는 구독한 실제 `runs`를 `CoursesScreen(..., runs = runs)`로 전달하며 DAO는 `ORDER BY rowid DESC`로 코스를 조회한다. 화면 API의 기본 emptyList는 기존 호출 호환용이며 실제 앱 연결을 대체하지 않는다.

## 행·빈 상태·기존 작업

카드와 중첩 여백을 없애고 구분선 사이의 이름/거리/목표/달린 횟수 요약으로 표시한다. 이름·요약은 줄 수와 고정 높이를 제한하지 않아 긴 이름·큰 글꼴에서 줄바꿈한다. 삭제는 독립 48dp 아이콘이고 이름을 포함한 접근성 설명, 이름 확인, 취소, 진행 중 잠금, 실패 재시도를 유지한다. 코스 행은 기존 코스/페이스 편집 진입을 보존한다.

추가는 배경 없는 48dp `+` 아이콘에서 코스만/코스·페이스 선택 시트로 연다. 페이스 계획 진입과 아이콘을 포함한 짧은 가져오기 버튼을 유지한다. 버튼은 큰 글꼴/작은 폭에서 공통 `AdaptiveActions`로 줄바꿈하며 + 공간은 별도로 확보한다. 가져오기는 기존 시스템 파일 선택, JSON/GPX 크기·좌표·구간·XML 검증 절차를 그대로 사용한다.

코스 자체가 없으면 **코스 없음**, 저장 코스는 있지만 필터 결과가 없으면 **달린 기록이 있는 코스 없음**과 **달린 기록 필터 끄기 · 전체 코스 보기** 조작을 제공한다. 오른쪽 체크도 항상 해제할 수 있어 기록 없는 새 코스를 편집·삭제할 수 있다.
