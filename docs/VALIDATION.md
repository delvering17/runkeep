# 검증 범위

## 자동 검사 설정

[Android 워크플로](../.github/workflows/android.yml)는 Temurin JDK 25와 JVM 21/JUnit 5 설정으로 core·simulation 단위 테스트, kakao/preview debug·simulation 네 variant 빌드와 lint를 실행하도록 구성되어 있다. 검사 명령과 보고서 업로드 범위는 워크플로 소스를 기준으로 한다. release 빌드, 서명된 배포와 instrumentation 실행은 이 설정의 성공 범위에 포함하지 않는다.

커밋별 통과 여부와 실행 보고서는 [GitHub Actions](https://github.com/delvering17/runkeep/actions)에서 확인한다. 워크플로의 요약에는 테스트 수·실패 수, variant별 lint 오류·경고 수와 JVM 타깃을 출력한다. 이 문서는 검사 구성과 범위를 설명하며, 이전 저장소의 검사 결과를 현재 커밋의 검증으로 대신하지 않는다.

## 현재 검증 범위

- 측정 엔진: 유효 위치의 거리 누적, GPS 불량·공백·튀는 좌표 제외, 운동 시간, 일시정지/재개, 목표 경계 보간과 전체 원본 보존, INTERRUPTED 복구.
- 자동 정지·재개: 제자리 좌표 흔들림·속도 오류, 연속 이동 확인, 수동 정지, 위치 만료·정확도 악화와 재개 시 경로 단절.
- 코스·계획: 지점 순서와 ID/방향성 목표 연결, 짧은 왕복·교차·GPS 공백·이탈, 편집/취소/실행 취소, v1/v2 JSON 호환과 크기 제한, 큰 편집·출발 사본의 cache 참조.
- 음성·박자 정책: 상태/현재/목표 선택, 대기 큐와 최신값, 실제 발화 시작을 기준으로 한 반복, 목표 이탈 경계, 단일 비트 출력·메트로놈 일정, 출력 중단과 늦은 세션 콜백의 분리. 합성 GPS 오디오 회귀는 실제 엔진의 이벤트를 확인한다.
- 화면의 순수 정책: 거리·시간·페이스 숫자 입력, 계산기와 초안 보존, 출발 선택 사본, 목록 정렬/필터, 기록 기간과 표시 범위, 차트의 시간·거리 매핑/단절/극값 축약, 지도 경로 갱신과 시작/끝 표식 배치, 파일 내보내기 상태.
- Health Connect 정책: 조회 시간 교집합과 출처 필터, 페이지 종료·중복·오류·취소, 샘플 유효성·DB 키, 가져오기 상태. 실제 제공자의 동기화와 반환 결과는 포함하지 않는다.
- simulation: 합성 위치 시나리오·사용자 지정 구간·저장/선택, 실제 RunEngine과 재생 입력의 연결. 가상 위치는 센서 케이던스나 심박수를 생성하지 않는다.

검사 구현은 [core 테스트](../core/src/test/kotlin/com/runkeep/core)와 [simulation 테스트](../app/src/testSimulation/java/com/runkeep/app)에 있다. 오디오 instrumentation 소스는 저장소에 있지만 현재 CI의 실행 대상은 아니다. 순수 수식·SQLite SQL·합성 비교 실험을 Android UI나 Room 제공자의 실행 검사로 표시하지 않는다.

## 기기 검증 한계

다음 항목은 자동 검사 설정으로 보장되지 않는다. 문서의 과거 화면 캡처도 현재 공개 커밋에서 다시 실행한 결과가 아니다.

- 실제 야외 GPS 수신·거리 오차·이탈 후 합류와 자동 정지/재개 지연, 화면 꺼짐·절전 중 장시간 기록과 배터리 사용량.
- 카카오 지도 키/패키지/서명 인증, 실제 지도 렌더링·제스처·끝점 표식과 장시간 native 성능.
- 휴대폰·폴더블의 실제 터치, 큰 글꼴·IME·회전/복구, TalkBack 낭독과 시스템 파일 선택/저장.
- 한국어 TTS·경보·메트로놈의 실제 청취, 무선 이어폰·음악·전화·오디오 포커스 전환과 출력 지연.
- Galaxy Fit3 → Samsung Health → Health Connect 동기화, 동일 기기의 실제 조회·권한·재가져오기와 Room 저장 경로.

기기 검증을 수행할 때 브랜치·커밋, 기기/OS/앱 버전, 설정과 재현 조건, 관찰한 결과를 남긴다. GPS 시뮬레이터의 합성 결과와 실측 결과를 구분한다. 사용 방법은 [GPS 시뮬레이터](GPS_SIMULATOR.md), 심박수 조사에 필요한 비식별 자료는 [심박수 가져오기 진단](HEALTH_IMPORT_DIAGNOSTICS.md)에 있다.
